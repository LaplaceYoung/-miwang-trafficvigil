# 密网巡哨 TrafficVigil 作品简介

## 一、作品名称

密网巡哨：融合多模态大数据的加密流量识别溯源系统  
英文名称：TrafficVigil

## 二、作品类别

网络空间安全类、人工智能应用类、数据科学与大数据分析类综合作品。

## 三、作品摘要

随着 HTTPS、TLS、QUIC、WireGuard 以及端到端加密即时通信工具的普及，互联网流量加密比例持续提升。加密技术提升了用户隐私保护能力，也让网络犯罪、非法交易、恶意组织协同和跨境黑灰产活动获得更隐蔽的通信通道。传统深度包检测方法难以读取加密载荷，基于简单统计特征的检测方法在短流、混合流和高噪声网络环境中稳定性有限，安全监管与取证分析面临新的技术挑战。

密网巡哨 TrafficVigil 围绕“混合流量识别、加密行为分析、公共群组溯源”三个核心问题，构建从流量采集、分层分类、行为嗅探到群组关联的全流程智能分析平台。系统以预训练模型学习通用网络流量表征，以 RIFA 数据增强和 SODF 多任务策略提升复杂场景下的鲁棒性，以双粒度图神经网络捕捉数据包内部字节关系和流量级上下文结构，并通过用户-设备-群组三维关系图谱完成公共群组匹配。

作品最终形成可交互的 Web 分析平台，支持 PCAP 文件上传、实时流量抓取、VPN/非 VPN 分类、加密即时通信识别、行为概率分析、群组关联推理和结构化报告生成。实验结果显示，系统在加密流量提取、用户行为分析和群组成员关联任务中分别达到 98.7%、90.2% 和 89.4% 的核心指标，具备较强的工程实用性与系统完整性。

## 四、系统交付成果

TrafficVigil 的交付成果包括 Web 可视化分析平台、本地分析流程、样例任务模板、结构化报告输出和提交材料截图。Web 平台覆盖登录注册、数据中心、流量捕获、综合检测、VPN 分析、SIM 分析、行为嗅探、群组匹配、报告中心、模型技术和系统设置等页面；本地分析流程负责 PCAP 读取、分层分类、行为分析、群组匹配和报告生成；报告输出以 JSON、CSV、PDF 和 PNG 长图支撑安全研判与材料编排。

完整使用路径为：授权 PCAP 或实时抓取流量进入系统，经过预处理、VPN/非 VPN 分类、SIM/非 SIM 分类、应用识别、行为嗅探和公共群组匹配后，最终在报告中心形成结构化结论。该交付形态同时满足系统运行、竞赛答辩、结果复核和后续扩展四类需求。

## 五、项目背景

近年来，网络通信协议逐步向全链路加密演进。HTTPS 已成为网页访问主流方式，TLS 1.3、QUIC、WireGuard 等新型协议提升了通信保密性和传输效率。Telegram、Signal、WhatsApp 等端到端加密即时通信工具广泛应用于个人通信、跨境协作和社群运营。加密通信在保护合法用户隐私方面具有重要价值，同时也让安全部门在面对恶意群组、非法交易、敏感文件传播和隐蔽组织协同时面临更高识别成本。

传统流量检测技术主要包括端口规则、协议字段解析、深度包检测和手工统计特征分类。面对加密载荷时，端口和协议字段的判别能力下降，深度包检测失去明文基础，手工特征在短流、突发流和多应用混合场景下波动明显。深度学习方法能够自动提取复杂模式，但通常依赖大规模标注数据；图神经网络方法可以表达流量结构，但已有方法常以整条流为建模单位，粒度粗、噪声积累明显。

基于上述背景，密网巡哨将加密流量分析拆解为三个递进任务：第一步从复杂混合流量中分离 VPN 与加密即时通信流量；第二步在加密通信载荷受保护的条件下识别用户行为；第三步结合元数据、时序模式和跨协议交互特征推理公共群组关系。该路径符合真实网络中的分析流程，也便于在竞赛答辩中呈现技术闭环。

## 六、系统目标

1. 构建完整的加密流量分析平台，实现数据输入、模型推理、结果展示和报告输出闭环。
2. 提升混合流量环境下 VPN 与加密即时通信流量的识别准确率。
3. 在加密载荷条件下，通过字节结构、包序列、时序关系和流量图特征识别用户行为。
4. 利用多模态关系图谱完成用户、设备和公共群组之间的关联推理。
5. 提供适合安全人员使用的可视化面板，降低复杂模型结果的理解门槛。
6. 输出符合计算机设计大赛提交要求的作品主页、README、作品简介和效果截图。

## 七、功能模块

### 1. 用户与任务入口

平台提供作品总览、任务批次、数据中心、分析流程和报告输出入口。用户可以围绕一次流量分析任务查看输入文件、处理进度、模型结果和风险研判信息。

[图片占位：任务入口页面截图]

### 2. 流量采集模块

系统支持两种输入方式：PCAP/PCAPNG 文件上传和实时抓包。上传模式适合复现实验、离线复核和离线分析；实时抓包模式适合网关、实验室环境和运营商侧的持续监测。流量进入系统后会完成会话切分、基础元数据抽取、方向标记、时间序列整理和协议提示生成。

[图片占位：PCAP 上传与实时抓包页面截图]

### 3. 多层分类模块

多层分类模块是系统的核心入口模型。第一层完成 VPN 与非 VPN 分类，第二层在加密流量中识别加密即时通信流量，第三层进一步识别 Telegram、WhatsApp、Signal、WeChat 等应用类别。分类结果以概率分布、堆叠图、批次摘要和协议覆盖列表展示。

[图片占位：流量分类结果页面截图]

### 4. 行为嗅探模块

行为嗅探模块面向加密即时通信流量，识别 chat、photo、file、video 等行为类型。系统基于字节级图和流量级拓扑图进行联合建模，将数据包内部字节关系、包序列方向、时间间隔、包长分布和会话上下文特征融合到统一表示中。结果以行为概率条形图、Top 会话卡片和批次分析结论展示。

[图片占位：行为嗅探概率分布图]

### 5. 群组关联模块

群组关联模块通过用户-设备-群组三维关系图谱完成公共群组匹配。系统将用户、终端设备、公共群组抽象为异构图节点，将流量交互、时间依赖、协议转换和行为相似度抽象为多类型边。通过图表示学习和跨边注意力机制，系统给出群组关联概率、高风险频道命中数量和跨设备关联链路。

[图片占位：用户-设备-群组三维关系图]

### 6. 报告生成模块

报告生成模块将模型输出转化为结构化分析报告。报告包含任务编号、输入数据、分类结果、行为识别结果、群组关联结果、核心指标、风险等级和处置建议。该模块适合连接安全运营流程，也适合在竞赛材料中呈现系统完整性。

[图片占位：分析报告页面截图]

## 八、技术方案

### 1. 预训练模型驱动的流量表征

系统使用大规模通用网络流量进行预训练，使模型学习协议交互、包序列模式、方向关系和字节分布等底层特征。预训练阶段缓解标注数据稀缺问题，微调阶段将模型能力迁移到加密即时通信识别任务中。该方案提升了模型对新协议、新应用和复杂混合流量的适应能力。

### 2. RIFA 数据增强与噪声鲁棒训练

真实网络中存在普通应用流量、VPN 封装流量、即时通信流量、重传报文、网络抖动和突发连接。系统引入随机初始化字段增强和噪声注入机制，使模型聚焦稳定、有判别性的协议结构与流量行为特征。该策略提升了模型在 QQ、微信、Telegram 等多应用混合场景下的稳定表现。

### 3. 双粒度图神经网络

系统在微观层面构建字节级图，以点互信息刻画数据包内部字节之间的关联；在宏观层面构建包级与流级拓扑图，表达会话上下文和通信结构。两个粒度的图表示通过融合模块进行交互，最终由 GATv2 等图神经网络完成分类预测。该设计兼顾细粒度字节模式和全局行为结构。

### 4. 多模态关系图谱

群组关联任务需要同时理解流量元数据、时序行为、设备关系和跨协议交互。系统构建用户-设备-群组三维关系图谱，将多源信息统一为异构图结构。图谱推理模块输出成员关联概率和风险关系链路，为加密群组治理提供可解释依据。

## 十一、测试与效果

作品书中给出的核心实验结果表明，TrafficVigil 在加密流量提取、行为分析、群组关联和混合流量处理方面均取得较好效果。系统在加密流量提取任务中达到 98.7% 准确率，在用户行为分析任务中达到 90.2% 准确率，在 Telegram 群组成员关联任务中达到 89.4% 准确率。混合流量处理吞吐量达到 6.32Gbps，首包响应时间达到 0.38ms。

这些指标分别对应系统的三个核心价值：识别得准、分析得细、运行得快。竞赛答辩时建议将指标与页面截图配合呈现，使评审能够快速理解系统的工程价值。
