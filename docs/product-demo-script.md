# TrafficVigil 密网巡哨产品演示脚本与口播稿

## 演示定位

本演示面向作品评审场景，目标是在 6 到 8 分钟内完整呈现“从流量接入、自动检测、多模态分析、群组溯源到报告生成”的闭环能力。演示节奏以产品操作为主线，口播围绕能力价值、关键技术和结果可信度展开。

## 演示前准备

1. 打开线上系统：`https://laplaceyoung.github.io/-miwang-trafficvigil/`
2. 登录账号：`judge_2026`
3. 登录密码：`abc12345`
4. 准备演示文件名：`sample-flow.pcap`
5. 浏览器建议分辨率：`1440x900` 或 `1536x864`
6. 演示顺序：登录页 → 数据中心 → 流量捕获 → 综合检测 → VPN 分析 → SIM 分析 → 行为嗅探 → 群组匹配 → 报告中心 → 模型展示

## 分镜脚本

### 1. 开场与登录

操作：
1. 打开系统首页。
2. 输入账号 `judge_2026` 和密码 `abc12345`。
3. 点击“登录系统”。

口播：
> 各位评委老师好，我们展示的是 TrafficVigil 密网巡哨，一套融合多模态大数据的加密流量识别溯源系统。系统面向暗网通信、隐蔽代理、IM 加密应用和公共群组关联分析场景，提供从流量接入到报告生成的全流程分析能力。现在进入控制台，展示完整检测链路。

### 2. 数据中心总览

操作：
1. 停留在“数据中心”。
2. 鼠标悬停实时流量态势折线图。
3. 鼠标悬停或点击加密流量构成环形图。
4. 点击 IM 应用分布柱状图中的 Telegram 或 WhatsApp。

口播：
> 数据中心汇总当前系统的全局态势，包括任务数量、PCAP 文件处理规模、混合流量识别成功率、SIM 提取准确率和群组匹配准确率。中部图表支持悬停查看数据点，也支持点击进入对应分析页面。这里的 IM 应用分布使用官方应用图标展示，能够让分析员快速识别 Telegram、WhatsApp、Signal、WeChat、QQ 等应用占比。

### 3. 流量捕获与数据接入

操作：
1. 进入“流量捕获”。
2. 展示初始状态：尚未选择文件、任务状态为待启动、下方为等待态。
3. 点击文件上传区，选择 `.pcap` 或 `.pcapng` 文件。
4. 展示上传进度。
5. 点击“开始抓取”，展示抓取进度、数据包动态统计和数据包预览表。

口播：
> 流量捕获中心支持两种数据接入方式：PCAP 文件上传和实时网卡抓取。页面会根据真实操作展示状态，在选择文件前保持等待态；选择合法后缀文件后才显示上传进度；点击开始抓取后，系统开始生成抓取进度、数据包统计和协议预览。这样的状态驱动设计符合实际安全分析工作流，也便于评审观察每个操作带来的即时反馈。

### 4. 综合检测工作台

操作：
1. 进入“综合检测”。
2. 展示初始状态：选择 PCAP、检测模式、目标协议、目标应用。
3. 上传 `sample-flow.pcap`。
4. 点击“开始综合检测”。
5. 等待步骤条、日志、环形进度和候选分布图生长出来。

口播：
> 综合检测工作台是一键式端到端检测流程。系统按八个阶段执行：选择流量数据、流量预处理、VPN 分类、SIM 分类、IM 应用分类、行为嗅探、公共群组匹配和报告生成。启动后，步骤状态、运行日志、置信度图表和阶段指标会逐步生成，模拟真实模型流水线的处理节奏。图表采用进入页面后的生长动画，帮助分析员感知检测结果正在逐步汇聚。

### 5. VPN 流量分析

操作：
1. 进入“VPN 分析”。
2. 展示 VPN / 非 VPN 分类环形图。
3. 悬停协议分布柱状图。
4. 使用搜索框输入 `WireGuard`。
5. 点击“导出分类结果”或“保存 VPN 流量”。

口播：
> VPN 分析模块将流量划分为 VPN 与普通加密流，并进一步展示 TLS 1.3、QUIC、WireGuard 等协议分布。右侧模型解释展示关键特征贡献，包括连接时长、包方向比例、TLS 指纹和端口组合。分析员可以通过搜索和筛选定位 WireGuard 等协议流，也可以导出分类结果或保存过滤后的 VPN 流量。

### 6. SIM 与 IM 应用识别

操作：
1. 进入“SIM 分析”。
2. 展示 SIM / 非 SIM 分类。
3. 点击 IM 应用识别分布中的 WhatsApp 或 Telegram。
4. 观察表格筛选结果变化。
5. 点击保存对应应用流量。

口播：
> SIM 分析模块针对过滤后的 VPN 流量进行 IM 应用识别，输出 Telegram、WhatsApp、Signal、WeChat、QQ 等应用概率。柱状图可以直接点击筛选表格，表格会同步展示对应 Flow ID、Top1 概率和多应用置信度。系统还支持按应用导出流量文件，便于后续取证复核。

### 7. 用户行为嗅探

操作：
1. 进入“行为嗅探”。
2. 展示包级流量图建模流程。
3. 悬停行为概率雷达图或排名条。
4. 打开实例详情。
5. 悬停“包长序列”和“时间间隔序列”折线图采样点。

口播：
> 行为嗅探模块将加密流量转换为包级流量图，提取包长、方向、时间间隔和突发模式，再通过图神经网络输出行为概率。右侧实例详情提供更细的时序统计，包长序列和时间间隔序列包含坐标、采样点和悬浮数据预览，能够支撑分析员判断聊天、文件、语音、视频等行为类型。

### 8. 公共群组匹配与溯源

操作：
1. 进入“群组匹配”。
2. 点击关系图中的 Group_Bravo 或其他群组节点。
3. 打开“配置”，切换显示证据连线、突出高危节点。
4. 使用风险等级筛选和搜索。

口播：
> 群组匹配模块将用户、设备、流量、群组和平台构成三维关系图谱。分析员点击群组节点后，右侧会展示平台、Group ID、成员数量、创建时间、匹配概率和证据链。这里体现的是从单条加密流量到公共群组线索的跨层关联能力。

### 9. 报告中心

操作：
1. 进入“报告中心”。
2. 依次点击左侧不同报告。
3. 展示每份报告的风险评分、基础信息、捕获摘要、分类结论和证据链说明均发生变化。
4. 点击导出 PDF、CSV、JSON。
5. 返回“任务历史”，分别点击 TASK-20250519-0001、TASK-20250519-0007、TASK-20250519-0010 的“查看报告”，展示任务与报告的一对一对应关系。

口播：
> 报告中心会为每个任务生成独立报告。不同任务拥有独立的源 IP、目的 IP、协议、设备类型、风险评分、分类结论和证据链说明。评审时可以切换报告观察内容变化，也可以直接导出 PDF、CSV 和 JSON，满足归档、审计和后续研判需要。

### 10. 模型与技术展示

操作：
1. 进入“模型展示”。
2. 展示系统技术架构和预训练到推理流程。
3. 展示性能指标和方法对比表。

口播：
> 模型展示页说明系统技术路线：通用网络流量预训练、SIM 专项微调、字节级图建模、多模态融合、图神经网络推理和报告生成。系统将流量元数据、时序模式、协议指纹和跨协议交互统一建模，形成可解释的检测结果。

## 完整口播稿

各位评委老师好，我们展示的是 TrafficVigil 密网巡哨，一套融合多模态大数据的加密流量识别溯源系统。系统面向暗网通信、隐蔽代理、IM 加密应用和公共群组关联分析场景，提供从流量接入、自动检测、行为分析、群组溯源到报告生成的完整工作流。

登录后进入数据中心。这里展示当前系统的任务规模、PCAP 文件处理量、混合流量识别成功率、SIM 提取准确率、行为分析准确率和群组匹配准确率。页面中的折线图、环形图和柱状图都支持悬停查看数据，点击后能够进入对应分析模块。IM 应用分布使用官方图标展示 Telegram、WhatsApp、Signal、WeChat 和 QQ，让应用识别结果更直观。

接下来进入流量捕获中心。系统支持 PCAP 文件上传和实时网卡抓取两种方式。页面初始保持等待状态，选择 `.pcap` 或 `.pcapng` 文件后显示上传进度；点击开始抓取后，抓取进度、数据包动态统计和数据包预览表会实时出现。这个页面强调真实操作驱动的数据状态，分析员每一步操作都会得到明确反馈。

进入综合检测工作台后，系统按照八个阶段执行端到端检测：流量数据选择、预处理、VPN 分类、SIM 分类、IM 应用分类、行为嗅探、公共群组匹配和报告生成。上传样例流量文件并启动检测后，步骤条、运行日志、进度环图和候选分布会逐步生长出来，体现模型流水线的处理过程。

VPN 分析模块会把流量划分为 VPN 与普通加密流，并展示 TLS 1.3、QUIC、WireGuard 等协议分布。模型解释区给出连接时长、包方向比例、TLS 指纹和端口组合等关键特征贡献。分析员可以搜索 WireGuard 等协议流，导出分类结果，也可以保存过滤后的 VPN 流量文件。

SIM 分析模块进一步识别 IM 应用类型。系统输出 Telegram、WhatsApp、Signal、WeChat、QQ 等应用概率，点击柱状图后表格会同步筛选对应 Flow ID。这里既能查看 Top1、Top2 概率，也能保存指定应用的流量文件，便于取证和复核。

用户行为嗅探模块将加密流量转换为包级流量图，提取包长、方向、时间间隔和突发模式，再通过图神经网络输出聊天、图片、文件、语音、视频等行为概率。实例详情中的包长序列和时间间隔序列提供坐标、采样点和悬浮预览，支撑分析员判断具体行为类型。

公共群组匹配模块将用户、设备、流量、群组和平台构成三维关系图谱。点击群组节点后，右侧展示平台、Group ID、成员数量、创建时间、匹配概率和证据链。该模块体现了从加密流量到公共群组线索的跨层关联能力。

报告中心会为每个分析任务生成独立报告。切换不同任务时，源 IP、目的 IP、协议、设备类型、风险评分、分类结论和证据链说明都会对应变化。报告支持 PDF、CSV 和 JSON 导出，满足归档、审计和后续研判需要。

最后看模型展示页。系统采用通用网络流量预训练、SIM 专项微调、字节级图建模、多模态融合和图神经网络推理，将流量元数据、时序模式、协议指纹和跨协议交互统一建模，输出具备解释链路的检测结果。TrafficVigil 密网巡哨的核心价值，是把加密流量识别、行为理解和群组溯源整合为面向实战的分析闭环。

## 评审演示提示

1. 鼠标悬停图表时停留 1 到 2 秒，让 tooltip 完整出现。
2. 在“流量捕获”和“综合检测”页面先展示等待态，再启动流程。
3. 报告中心至少切换三份报告，展示每份报告内容差异。
4. 行为嗅探页重点展示右侧折线图采样点，因为这里最能体现细节真实感。
5. 演示收尾落在“模型展示”页面，便于承接技术创新说明。
